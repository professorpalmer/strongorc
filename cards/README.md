# Cards

Dated JSON scorecards from `strongorc card`.

A card is earned on this harness only. Do not copy `orch_score` / `leaf_score` into a product `capability_score`. A later overlay may cite `harness_version`, `date`, and this file.

Harness 0.2.0 added `outcome_rate` / `protocol_rate` / check-level rates and grew `hard` from 4 tasks to 16. `glm-5.3.json` is a 0.1.0 card on the four-task floor — not comparable to a 0.2.0 hard card.

`scripted-pass.json` is the oracle-non-vacuity baseline, not a model result.
